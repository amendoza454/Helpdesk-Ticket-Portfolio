## Troubleshooting Methodology

Each incident follows a structured troubleshooting process:

1. **Identify the Problem:** Review the reported issue and affected systems.
2. **Investigate:** Gather information using Windows administration tools.
3. **Determine Root Cause:** Identify the underlying technical issue.
4. **Implement Resolution:** Apply the appropriate corrective action.
5. **Verify:** Confirm that the affected service or resource works.
6. **Document:** Record troubleshooting steps, results, and supporting evidence.
